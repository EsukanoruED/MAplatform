One-sentence: a square 32/40/48px action with a single Lucide glyph — for toolbars, table rows, and dialog dismissals.

```jsx
<IconButton label="Print certificate" icon={<Icon name="printer" size={18} />} />
<IconButton label="Close" variant="ghost" icon={<Icon name="x" size={18} />} />
```

Never ship one without `label`.
